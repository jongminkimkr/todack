# 토닥+

학생의 심리상담 접근성을 높이는 상담·감정기록 앱.
**간편 상담 → 위클래스 상담 신청·예약 → 감정달력** 을 하나의 앱으로 연결합니다.

빌드 도구, 서버, 외부 라이브러리, 인터넷 없이 동작합니다.

---

## 실행하는 세 가지 방법

### 1. 컴퓨터에서 바로 (가장 간단)

```bash
open index.html          # macOS
start index.html         # Windows
```

더블클릭해도 됩니다. 설치할 것이 없습니다.

> **iPhone/Mac의 Safari 주의** — Safari는 `file://`로 연 문서에서 `localStorage`를 막을 수 있습니다.
> 그러면 감정 기록과 상담 신청이 저장되지 않는데, 앱이 그 사실을 **상단 빨간 띠로 알려 줍니다.**
> 기록을 남기려면 아래 2번(설치) 또는 3번(로컬 서버) 방법을 쓰세요.

### 2. 폰에 앱처럼 설치하기 (PWA)

배포된 주소를 폰 브라우저로 연 다음:

| 기기 | 방법 |
|---|---|
| **iPhone / iPad** | Safari에서 열기 → 공유 버튼 → **홈 화면에 추가** |
| **Android** | Chrome에서 열기 → 주소창 옆 설치 아이콘, 또는 메뉴 → **앱 설치** |

설치하면 주소창 없이 전체화면으로 뜨고, 홈 화면에 네잎클로버 아이콘이 생깁니다.
한 번 연 뒤에는 **인터넷이 끊겨도 열립니다** (서비스워커가 앱을 캐시합니다).

> Safari는 반드시 **Safari로** 열어야 「홈 화면에 추가」가 나옵니다. Chrome for iOS에는 없습니다.

### 3. 노트북에서 로컬 서버로 (같은 와이파이에서 폰 접속)

```bash
python3 -m http.server 8000
```

* 노트북에서: `http://localhost:8000`
* 같은 와이파이의 폰에서: `http://<노트북 IP>:8000`
  (IP 확인: macOS `ipconfig getifaddr en0` / Windows `ipconfig`)

`localhost`가 아닌 IP 접속은 `http://`라서 **서비스워커가 등록되지 않습니다.** 앱 기능은 모두 정상이고 오프라인 캐시만 빠집니다.

## GitHub Pages로 배포하기

폰에서 설치형으로 쓰려면 `https://` 주소가 필요합니다. GitHub Pages가 가장 간단합니다.

### 1단계 — 저장소에 올리기

```bash
# 아직 원격 저장소가 없다면 GitHub에서 새 저장소를 만든 뒤
git remote add origin https://github.com/<사용자명>/<저장소명>.git

# 작업 브랜치를 main으로 합치고 푸시
git checkout -b main 2>/dev/null || git checkout main
git merge feat/todak-plus
git push -u origin main
```

### 2단계 — Pages 켜기

저장소 페이지에서 **Settings → Pages**:

| 항목 | 값 |
|---|---|
| Source | **Deploy from a branch** |
| Branch | **main** / **`/ (root)`** |

**Save**를 누르고 1~2분 기다리면 주소가 나옵니다:

```
https://<사용자명>.github.io/<저장소명>/
```

이 주소를 폰에서 열어 홈 화면에 추가하면 됩니다. QR 코드로 만들어 두면 발표할 때 편합니다.

### 알아두실 것

* **공개 저장소면 누구나 코드와 앱을 볼 수 있습니다.** 학생 개인정보는 코드에 들어 있지 않고 각자 기기에만 저장되지만, 저장소 공개 여부는 확인하세요. 비공개로 두려면 GitHub Pages는 유료 플랜이 필요합니다.
* 모든 경로가 상대 경로라 `<저장소명>` 하위 경로에서도 그대로 동작합니다.
* `.nojekyll` 파일이 있어 GitHub이 파일을 임의로 걸러내지 않습니다.
* **앱을 수정한 뒤에는** `sw.js`의 `const CACHE = 'todak-v1'` 값을 `todak-v2`처럼 올려야 폰에 새 버전이 반영됩니다. 올리지 않으면 이전 캐시가 계속 뜹니다.

## 파일 구성

```
index.html              앱 전체 (HTML·CSS·JS·로고 모두 인라인)
manifest.webmanifest    홈 화면 설치 정보 (이름·아이콘·시작 주소)
sw.js                   서비스워커 — 오프라인 캐시
icons/                  네잎클로버 아이콘 (192·512·maskable·iOS·favicon)
.nojekyll               GitHub Pages가 파일을 거르지 않도록
요구 정의서.md            원본 기획서
docs/superpowers/plans/ 구현 계획서와 최종 검토 기록
```

`index.html` 하나만 있어도 앱은 완전히 동작합니다. 나머지는 폰 설치와 오프라인을 위한 것입니다.

## 개발 메모

브라우저 콘솔에서 순수 로직 테스트를 돌릴 수 있습니다.

```js
selfTest()      // 49건. true면 전부 통과
```

기록 초기화는 앱 안의 **홈 → 「이 기기에서 내 기록 모두 지우기」** 또는:

```js
localStorage.clear()
```

`index.html` 안은 `/* == TOKENS == */`, `/* == STORE == */`, `/* == VIEWS == */` 같은 주석 구획으로 나뉘어 있습니다.

## 꼭 알아두셔야 할 것

* **상담 신청은 실제로 전송되지 않습니다.** 신청 내용은 그 기기에만 저장됩니다. 앱도 완료 화면에서 이 사실을 명시하고, 약속한 시간에 위클래스를 방문하도록 안내합니다.
* **간편 상담은 전문 심리상담을 대체하지 않습니다.** 규칙 기반으로 고민을 분류해 생각해 볼 방법을 제안할 뿐입니다.
* 자해·자살과 관련된 표현이 감지되면 다른 어떤 응답보다 우선해서 **연출 없이 즉시** 도움 안내를 띄웁니다.
  자살예방 상담전화 **109**, 청소년 상담전화 **1388** (24시간, 무료)
* 여러 사람이 함께 쓰는 컴퓨터에서는 사용 후 홈 화면의 **「이 기기에서 내 기록 모두 지우기」** 를 눌러 주세요.
